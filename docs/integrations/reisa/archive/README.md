# Reisa Archive and Reference

This folder preserves historical planning snapshots and reference artifacts that are still useful, but are not the primary day-to-day docs.

- You need original planning rationale or historical assumptions.
- You need integration inventory/snapshot context for audits or reconstruction.

## When not to use archive docs
- For current status and next steps, prefer:
  - `../completed/README.md`
  - `../future/README.md`
