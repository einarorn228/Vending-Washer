Admin Command Examples
=======================
Purpose: comprehensive reference for administrators performing maintenance, configuration, and manual workflows on the Vending Washer system.

Conventions
-----------
- Run commands from the repository root (`Vending-Washer`).
- Replace angle-bracket placeholders (e.g., `<ORDER_ID>`) with real values.
- Unless otherwise noted, backend listens on `http://127.0.0.1:5000` and frontend on `http://127.0.0.1:3000`.
- Include both HTTP Basic auth (`-u <username>:<password>`) and the `X-API-KEY` header for admin routes.

Environment & Credentials
-------------------------
# Capture the generated kiosk API key
python backend/scripts/get_api_key.py

# Seed settings and hardware inventory on a fresh database
python -m backend.setup.seed_settings
python -m backend.setup.seed_machines

# PowerShell: store API key in current session for reuse
$env:API_KEY = "<PASTE_API_KEY>"

# bash/zsh: store API key
export API_KEY="<PASTE_API_KEY>"

# Inspect stored admin credentials (sqlite3 CLI)
sqlite3 backend/codes.db "SELECT key, value FROM settings WHERE key LIKE 'admin_%';"

QR Code Lifecycle
-----------------
# Generate a fresh QR code for an order (public endpoint, API key only)
curl -X POST -H "X-API-KEY: $API_KEY" -H "Content-Type: application/json" \
  -d '{"order_id": "<ORDER_ID>", "usage_limit": 3}' \
  http://127.0.0.1:5000/generate_code

# Manually validate a code via the kiosk API (logs to scan_logs)
curl -X POST -H "X-API-KEY: $API_KEY" -H "Content-Type: application/json" \
  -d '{"code": "<CODE_VALUE>"}' \
  http://127.0.0.1:5000/api/scan_code

# Start a machine for a valid code (telemetry will confirm and debit usage)
curl -X POST -H "X-API-KEY: $API_KEY" -H "Content-Type: application/json" \
  -d '{"code": "<CODE_VALUE>", "machine_id": "washer1"}' \
  http://127.0.0.1:5000/api/start_machine

# Trigger a start via Shelly i4 button mapping (button index from 0)
curl -X POST -H "X-API-KEY: $API_KEY" -H "Content-Type: application/json" \
  -d '{"button": 0}' \
  http://127.0.0.1:5000/api/i4_event

# Poll current UI state (includes machine telemetry snapshot)
curl -H "X-API-KEY: $API_KEY" \
  http://127.0.0.1:5000/api/ui_state

# Revoke a code once a job is finished (delete)
curl -X DELETE -u admin:<password> -H "X-API-KEY: $API_KEY" \
  http://127.0.0.1:5000/admin/codes/<CODE_VALUE>

Configuration & Settings
------------------------
# View any setting value
curl -u admin:<password> -H "X-API-KEY: $API_KEY" \
  http://127.0.0.1:5000/admin/settings/<SETTING_KEY>

# Update numeric/string settings (e.g., button_select_timeout_sec)
curl -X PUT -u admin:<password> -H "X-API-KEY: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"value": "60"}' \
  http://127.0.0.1:5000/admin/settings/button_select_timeout_sec

# Update CORS origins
curl -X PUT -u admin:<password> -H "X-API-KEY: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"origins": ["http://localhost:3000", "http://192.168.1.50"]}' \
  http://127.0.0.1:5000/admin/settings/cors

# Rotate the API key (redistribute new value afterwards)
curl -X PUT -u admin:<password> -H "X-API-KEY: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"value": "<NEW_API_KEY>"}' \
  http://127.0.0.1:5000/admin/settings/api_key

# Change admin password (hash first)
$NEW_PASS = "<newPassword>"
$HASH = (echo -n $NEW_PASS | openssl dgst -sha256).Split(" ")[-1]
curl -X PUT -u admin:<currentPassword> -H "X-API-KEY: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"value": "'"$HASH"'"}' \
  http://127.0.0.1:5000/admin/settings/admin_password_hash

Service Control
---------------
# Launch backend (virtualenv active)
python -m backend.app

# Stop backend (Ctrl+C in the backend terminal)

# Frontend dev server
cd frontend
npm install
npm run dev

# Production-ready frontend build
cd frontend
npm install
npm run build
npm run start   # serves static bundle via Vite preview

Maintenance Tips
----------------
- Rerun seed scripts after deleting `codes.db` or changing hardware inventory.
- Redistribute updated API keys or admin passwords immediately to all kiosks and automation scripts.
- Export database snapshots before running destructive operations in production environments.
- Monitor `backend/logs/app.log` during testing for serial scanner, Shelly, telemetry, and API errors.
